## 附录A　方法选择综合题思路（论述题高频）
**例：如何全面表征一种新制备的纳米TiO₂光催化粉体？**
1. **物相与晶粒尺寸**：XRD（锐钛矿/金红石鉴定、K值法/RIR测两相含量、谢乐公式算晶粒尺寸）；Raman 辅助物相（锐钛矿144 cm⁻¹）。
2. **形貌与粒径**：SEM（团聚形貌）、TEM（粒径、HRTEM晶格条纹d=0.35 nm对应锐钛矿(101)、SAED多晶环）。
3. **元素组成与掺杂**：EDS（元素面分布）、XPS（Ti⁴⁺/Ti³⁺价态、氧空位、掺杂元素化学态）、XRF（宏观成分）。
4. **光学性质**：UV-Vis DRS + Tauc图求禁带宽度（~3.2 eV）；PL谱（载流子复合）。
5. **表面基团**：FTIR（表面−OH、吸附物）。
6. **热稳定性**：TG-DSC（前驱体分解、晶型转变温度，锐钛矿→金红石放热无失重）。
7. **比表面积**：BET（氮气吸附）。

**例：判断一金属零件失效原因** → 宏观观察 + **SEM断口分析**（韧窝/解理/疲劳辉纹/沿晶）+ EDS（夹杂物成分）+ 金相 + 硬度 + XRD（残余应力）+ 无损检测（同批零件）。

## 附录B　易混概念辨析
| 易混点 | 区分 |
|---|---|
| XRD vs XRF | 衍射（物相，已知λ求d） vs 荧光（元素，已知d求λ） |
| EDS vs XRF | 电子激发微区（μm） vs X射线激发宏观；EDS有连续谱背底，XRF检测限更低 |
| XPS vs XRF | 都用X射线激发；XPS测光电子（表面nm级、化学态），XRF测荧光X射线（体相μm–mm、元素） |
| SE vs BSE | 形貌（<50 eV，表层） vs 成分（高能，Z衬度） |
| 质厚 vs 衍射 vs 相位衬度 | 非晶 vs 晶体 vs 极薄晶体高分辨 |
| 明场 vs 暗场 | 透射束成像 vs 衍射束成像 |
| 物镜光阑 vs 选区光阑 | 后焦面（衬度/明暗场） vs 像平面（选区衍射） |
| DTA vs DSC | 温差（定性） vs 热流（定量） |
| TG vs DTG | 质量 vs 质量变化速率 |
| IR vs Raman | 吸收/偶极矩/极性基团 vs 散射/极化率/非极性基团 |
| 斯托克斯 vs 反斯托克斯 | ν₀−Δν(强) vs ν₀+Δν(弱) |
| 屏蔽 vs 去屏蔽 | 高场δ小 vs 低场δ大 |
| K_I vs K_IC | 力学参量 vs 材料常数 |
| 软磁 vs 硬磁 | Hc小μ高（变压器） vs Hc大(BH)max大（永磁体） |
| 静态 vs 动态 SIMS | 表面单层分子信息 vs 深度剖析 |
| STM vs AFM | 隧道电流（仅导体） vs 原子力（绝缘体也可） |
